# 13.5 非递归先序与中序遍历

2026-11-19。先序采用老师讲义 §13.5 pp.243–244、图 13.18 的最左通路方法。中序的显式栈步骤为本轮笔试补充。上轮递归遍历错题已按用户确认登记为已订正。[学习记录](../../chapters/11-binary-tree/sessions/2026-11-19-iterative-pre-in-order.md)

沿用上轮的树。A 的左右孩子是 B、C，B 的左右孩子是 D、E，E 只有左孩子 G，C 只有右孩子 F。

```text
        A
       / \
      B   C
     / \   \
    D   E   F
       /
      G
```

栈表示为 `[栈底 … 栈顶]`，最右端是栈顶。C 代码的 `top` 记录元素个数，也就是下一个待写入位置。当前指针 `pn` 为 `NULL` 时，表示沿当前方向已走到空孩子。

## 先序 根、左、右

沿左路每到一个结点就输出它。遇到非空右孩子，先把它压栈，继续沿左孩子走。左路走完后，从栈顶取出最近留下的右子树根，重复这一过程。这样靠下的右子树先处理，符合先访问整棵左子树的顺序。

| 本次沿左路输出 | 途中压栈 | 到空孩子时的栈 | 下一棵子树的根 |
| --- | --- | --- | --- |
| A B D | C、E | `[C E]` | E |
| E G | 无 | `[C]` | C |
| C | F | `[F]` | F |
| F | 无 | `[]` | 结束 |

结果为 `ABDEGCF`。栈里保存已经访问过的结点所留下的**待处理右子树的根**。

## 中序 左、根、右

沿左路把**当前结点**压栈。走到空孩子时，栈顶结点的左子树已处理完，弹出并输出它，再将当前指针改为它的右孩子。

| 到达空孩子时的栈 | 弹出并输出 | 接着走向 |
| --- | --- | --- |
| `[A B D]` | D | 空 |
| `[A B]` | B | E |
| `[A E G]` | G | 空 |
| `[A E]` | E | 空 |
| `[A]` | A | C |
| `[C]` | C | F |
| `[F]` | F | 空，栈也空则结束 |

结果为 `DBGEACF`。例如访问 E 时，先把 E 压栈，再把它的左孩子 G 压栈，所以 G 先输出。栈里保存**尚未输出的结点**。

## C11 实现

复用上一轮 `BTNode` 定义，`plc`、`prc` 分别是左右孩子指针，空孩子为 `NULL`。`stack` 由调用者提供，非空树至少预留 `h+1` 个指针位置，或在已知结点数时预留 `n` 个位置。树高 `h` 按讲义用边数计算。空树直接结束。

```c
#include <stdio.h>

void PreOrderIter(const BTNode *pn, const BTNode *stack[])
{
    size_t top = 0;
    while (pn != NULL || top > 0) {
        while (pn != NULL) {
            putchar(pn->key);
            if (pn->prc != NULL) {
                stack[top++] = pn->prc;
            }
            pn = pn->plc;
        }
        if (top > 0) {
            pn = stack[--top];
        }
    }
}

void InOrderIter(const BTNode *pn, const BTNode *stack[])
{
    size_t top = 0;
    while (pn != NULL || top > 0) {
        while (pn != NULL) {
            stack[top++] = pn;
            pn = pn->plc;
        }
        pn = stack[--top];
        putchar(pn->key);
        pn = pn->prc;
    }
}
```

两种算法在最优、平均、最坏树形下时间均为 Θ(n)（n ≥ 1），每个结点输出一次，最多各入栈和出栈一次。实际栈占用上界为 O(h+1)，中序纯左链可达到 Θ(n)，纯右链的栈峰值为 1；先序纯左链无需压栈。若直接声明容量为 n 的数组，分配的额外空间为 Θ(n)，即使其中实际用到的位置较少。空树时间为 Θ(1)。

```text
      M
     / \
    J   T
   / \ /
  H  K P
```
