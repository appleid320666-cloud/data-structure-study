## 约定与示例

根深度为 0，树高为最大深度。下面是讲义 Figure 13.4（p.228）使用的树形。e 只有右孩子 f。

```text
        d
       / \
      b   g
     / \ /
    a  c e
          \
           f
```

## 结点如何存储

每个结点存关键码 key，以及父结点指针 ppa、左孩子指针 plc、右孩子指针 prc。空孩子用 NULL，根的 ppa 为 NULL。普通二叉链表也常只存左右孩子；老师讲义为了直接查询父结点，还存了父指针。

老师的图 13.5 有额外的构造检查数据，本轮只取理解树形和遍历需要的这些字段。讲义的 C++ 成员函数在 C 中写为普通函数，显式接收结点指针。

```c
typedef struct BTNode {
    char key;
    struct BTNode *ppa;
    struct BTNode *plc;
    struct BTNode *prc;
} BTNode;
```

`BTNode *pn` 表示 pn 存放一个结点的地址；`pn->key` 读取该结点的关键码；`pn->plc` 取得左孩子地址。例如 pn 指向 e，则 pn->ppa 指向 g，pn->plc 为 NULL，pn->prc 指向 f。`pn->prc->key` 才是字符 f，使用前需确保相应指针有效。

给定结点指针，有父指针时访问父结点为 O(1)。只有孩子指针时，已知根并查找任意结点的父结点，最坏需要遍历，时间为 O(n)。

讲义用向量保存所有结点，结点间仍用指针表示父子关系。向量中的存放位置不自动代表树上的层次位置。

## 遍历中的“先、中、后”

以每棵子树的根为参照，先序为“根、左子树、右子树”，中序为“左子树、根、右子树”，后序为“左子树、右子树、根”。三者都先处理完整左子树再处理完整右子树。访问根的位置不同。

在根 d 处，先将树分成 d、以 b 为根的左子树、以 g 为根的右子树。每棵子树内部继续使用同一规则。

| 遍历 | 左子树结果 | 右子树结果 | 整棵树结果 |
| --- | --- | --- | --- |
| 先序 | b a c | g e f | d b a c g e f |
| 中序 | a b c | e f g | a b c d e f g |
| 后序 | a c b | f e g | a c b f e g d |

右子树的中序为 e f g。e 的左子树为空，先返回，再访问 e，然后访问其右孩子 f，最后回到 g 并访问 g。中序遍历不会自动排序任意二叉树的关键码，当前字母有序是这个示例的特点。

笔试可先写三段的组合，再递归展开，尤其保留单孩子结点的左右位置。

## C 递归算法

输入为已经构建好的有效、无环二叉树的根指针，所有空孩子均已设为 NULL。字符输出作为访问操作。以下 C11 算法对应讲义 Figure 13.11（p.235）的三种 C++ 递归成员函数。

```c
#include <stdio.h>

void PreOrder(const BTNode *pn)
{
    if (pn == NULL) {
        return;
    }
    putchar(pn->key);
    PreOrder(pn->plc);
    PreOrder(pn->prc);
}

void InOrder(const BTNode *pn)
{
    if (pn == NULL) {
        return;
    }
    InOrder(pn->plc);
    putchar(pn->key);
    InOrder(pn->prc);
}

void PostOrder(const BTNode *pn)
{
    if (pn == NULL) {
        return;
    }
    PostOrder(pn->plc);
    PostOrder(pn->prc);
    putchar(pn->key);
}
```

NULL 判断必须在访问 key 或孩子指针之前。递归返回表示当前子树处理完毕，继续执行调用它的那一层函数；不是回到整棵树根重新开始。这里只递归左右孩子，父指针 ppa 用于其他操作。

设 n 为实际结点数，每个结点的访问为 O(1)。三种遍历都访问所有结点，时间在最好、平均、最坏树形下均为 Θ(n)（n≥1），空树为 Θ(1)。递归额外空间为 Θ(h+1)，包含调用栈；平衡树为 Θ(log n)，退化链为 Θ(n)。平均空间取决于树形分布，题目未给分布时不单列确定的平均界。
