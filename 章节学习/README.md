## 以后如何整理

- 每个知识点或一组相关习题单独保存为 Markdown，命名使用“节号或题号-主题.md”，便于查找。
- 笔记按需要包含概念、示意图、手工推演、笔试写法、复杂度及易错点；自 2026-10-22 起优先使用 C，Python 按需辅助理解，老师的 C++ 写法按需对照。题目指定的语言和接口优先。
- 将老师原文、解题推导和课件疑点分清；题目无需代码时，突出示意图和文字答案。
- 学习中形成需要留存的知识点笔记时，保存到对应章节，并更新本页“已整理的笔记”；不为尚未讲解的内容预先生成空泛笔记。
