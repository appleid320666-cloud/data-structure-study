## 第 1 段：字符串的基本性质

### 字符串、字符表与长度

字符串是有限个字符组成的序列，顺序有意义。字符表 Σ 表示允许使用的字符集合，D 是字符表大小；n 是某个具体字符串的长度，两者不是同一个量。

自编例：Σ={a,b,c}，则 D=3；S=abac，则 n=4。字符串可以反复使用字符表中的同一个字符。

下标从 0 开始，S 的字符位置为 0 到 n−1，区间统一用左闭右开。

空串没有字符，长度 0；只含一个空格的串长度 1。以下例子均按 ASCII 单字节字符解释，不把多字节编码的字节数混当字符数。

**C 对照（补充表示法）：** 用带结束标记的字符数组存储 abc，需要 a、b、c、\0 四个数组元素，但字符串逻辑长度是 3；\0 是结束标记，不计入串长。数组容量、字符串长度要区分。

### 子串、前缀与后缀

- 子串必须是原串中连续的一段。例如 abca 中的 bc 是子串；ac 不能通过跳过中间字符得到子串。保持顺序但允许跳过的叫子序列，作为概念对照。
- 前缀是从最左端开始的一段；后缀是到最右端结束的一段。
- 真前缀、真后缀排除整串本身。构造普通 Next 时寻找的是相等真前后缀；非空候选不存在时允许长度 t=0。
- 例如 abca 的首尾都能取到 a；但 abc 与 bca 不相等。必须按同方向逐字比较，不能把镜面对称当成相等。

### 两个串什么时候相等

长度相同，并且所有对应位置字符都相同，才相等。abc 与 abc 相等；abc 与 abd 不相等；abc 与 abca 也不相等。

若长度已知，长度不同可立即判不等；长度相同则逐字符比较，第一次不同即可停止，最坏需要比较 n 个字符。这里讨论相等判断，不是字典序比较。

### ADT 与具体语言的关系

ADT 描述“可以做哪些操作”，比如求长度、取子串；具体语言决定如何存储和实现。课件 §7.2 简要介绍 C++ STL string 作为实现例子，不应把 C++ 的 string 容器直接当成 C 的类型。后续算法实现用 C 时，再结合题目定义字符数组、长度和容量。
