## 材料使用顺序

用户提供的本校最新范围/通知 → 本校课件与指定教材相互对照 → 本校公开历年题 → 广东其他高校公开卷 → 明确标注的自编练习。

课件第 11 页推荐多本教材，其中包含李春葆第七版与邓俊辉 C++ 版；本仓库以用户明确指定的李春葆第七版为教材，不把推荐清单全部列为必读。

课件有传统数据结构以外的第 3、14、15 章。未获教师范围前仍保留并准备，不因外校少考而删去；也不从作业覆盖范围推断全部考试范围。

## 尚待核验，不阻碍按课件开始

- 教材版权页与目录：用于核实完整书名、ISBN、精确节号/页码；目前只建立主题对照，不编造页码。
- 本校今年实际考试范围、日期、题型与分值、算法题能否使用 C 伪代码。
- 本校公开历年卷：本次尚未核验到对应课程试卷，不能用其他学校卷替代。
- 学生当前章节和基础：通过 `exams/diagnostic.md` 的自编小测了解，不预设已学会。

## 提取与引用课件

课件印刷页码与 PDF 物理页序当前一致。引用采用“第 7 章 §7.6，PDF pp.179–190”等写法，并链接到原 PDF。`pdftotext` 提取的数字、英文字母和部分汉字存在字体映射乱码；涉及公式、图、代码、next 表必须回看 PDF，不将批量字符替换结果当作原文。
