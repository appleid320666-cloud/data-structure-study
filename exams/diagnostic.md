# 起点诊断：自编题，非高校真题

用途：了解概念和手算基础。建议 25 分钟、每题 5 分，共 40 分；时间与分值均为自拟。先独立作答，再展开解析。未作答不填写分数或掌握结论。

1. 说明逻辑结构与存储结构的区别，并以线性表举例。
2. 求以下语句执行 `count++` 的次数与 Θ 复杂度：`for(i=0;i<n;i++) for(j=0;j<=i;j++) count++;`，设 n≥1，不考虑整数溢出。
3. 在递增数组 `[2,5,8,12,16]` 查找 12，采用下标从0、闭区间 `[lo,hi]`、`mid=lo+(hi-lo)/2` 的二分，逐步写 lo、hi、mid。
4. 带头结点单链表中 p 指向某数据结点，p 有后继。写出删除后继并释放内存的三步，说明为何不能先释放再访问它。
5. 1、2、3 依次入栈，中途允许出栈。`3,1,2` 能否为输出序列？说明过程。
6. 容量为8的循环队列，front 指向队首、rear 指向下一个入队位置，牺牲一格区分空满。front=6、rear=2 时队长多少？再入队后 rear 是多少？
7. 根A，左子B、右子C，B只有右子D。写先序、中序、后序和层序序列。
8. 无向图邻接表：A:[B,C]，B:[A,D]，C:[A,D]，D:[B,C]。从A出发，按表中顺序访问邻居，BFS入队即标记、DFS首次进入即标记。分别写访问序列及两种遍历的时间复杂度。

<details>
<summary>参考解析与自拟评分点（独立作答后查看）</summary>

1. 逻辑结构指数据元素之间的关系；存储结构指在计算机中的表示。线性关系可用连续数组或链接结点表示。概念各2分，例子1分。
2. 次数为 `1+2+…+n=n(n+1)/2`，Θ(n²)。求和式2分、精确次数1分、阶与解释2分。
3. `(0,4,2)` 对应8，小于12，lo变3；`(3,4,3)` 对应12，返回3。每轮2分，结果1分。
4. 前提 p 与 p->next 非空：`q=p->next; p->next=q->next; free(q);`。保存/重连/释放各1分；解释释放后不能再读 q->next、头结点不误删共2分。
5. 不能。为了先输出3，必须压入1、2、3；弹3后栈顶是2，无法立即输出1。结论1分，过程4分。
6. `(2-6+8)%8=4`；入队位置2，之后 rear=3。队长2分，rear更新2分，区分容量8与最大可存7个1分。
7. 先序 A B D C；中序 B D A C；后序 D B C A；层序 A B C D。每种1分，能解释访问规则1分。
8. BFS A B C D；DFS A B D C；邻接表均 O(V+E)，含对顶点的检查与对邻接表的扫描。两个序列各2分，复杂度及存储条件1分。

</details>
