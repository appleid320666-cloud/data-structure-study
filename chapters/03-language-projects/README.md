## 笔试准备重点

二分求零点、不动点迭代与稳定性；投针问题与 Vicsek 模型。

## 本章需要独立完成

手算一次迭代并解释终止条件；区分数值二分与有序表二分查找。

先讲概念、适用条件、手算过程和复杂度，再用伪代码与 C11 辅助理解。Python 仅在有助于验算时使用。
