## 笔试准备重点

数据、数据结构、算法、抽象数据类型；结构与操作的关系。

## 本章需要独立完成

给出同一逻辑结构的两种存储方式，说明算法的输入输出。

先讲概念、适用条件、手算过程和复杂度，再用伪代码与 C11 辅助理解。Python 仅在有助于验算时使用。

1. 本章的核心定义、前提条件与相邻章节有何联系？
