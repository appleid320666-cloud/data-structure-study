现有样本最支持的学习策略是：**围绕课堂算法练手工过程、关键代码与复杂度论证，再用外校题检验迁移能力。** 单纯背定义或只运行程序，不足以覆盖这些卷子的要求。

## 二、从样本提炼的考法

### 1. 纸面输出值得分配主要训练时间

完整可核对的中大 2010 秋、中大 2011 秋、广工 2014 三卷，非客观部分分别为 70、70、76 分（广工附加题不计）。这里把解答、算法填空和算法设计归为非客观部分。

这是三份旧卷的描述，不是广东高校平均值，更不是当前华师卷的预测。它的实际启示是：训练不能只停留在“认得概念、看得懂代码”。

### 2. 同一算法会从不同角度提问

| 考查方式 | 常见要求 | 训练动作 |
| --- | --- | --- |
| 概念辨析 | 区分逻辑／存储结构、复杂度与稳定性 | 给出定义，并能构造一个反例 |
| 手工执行 | 写若干趟排序、匹配跳转或结构变化 | 逐步列状态、变量和选择理由 |
| 代码填空 | 补遍历、重连、边界判断 | 先说每个变量的含义，再补语句 |
| 算法设计 | 实现基本操作，满足空间或时间限制 | 写输入、输出、步骤、关键代码和复杂度 |
| 综合应用 | 把情境转换为已学数据结构／算法 | 先识别模型，再计算或实现 |

这些是样本要求的归纳，不是需要背诵的固定题型模板。

### 3. 限制条件往往决定能否得分

常见限制包括：指定首元素为轴点；不新建链表节点；要求递归或非递归；按给定顺序访问相邻节点；只写前几趟；统计比较次数。

因此拿到题目先标注：**结构、下标起点、区间、相等时的处理、允许的额外空间、要求展示的中间步骤。** 最终结果正确，也不能替代题目要求的过程。

## 四、落实到日常学习

### 每个算法建立“一题四问”

1. **是什么**：输入输出是什么，需要什么结构和前提？
2. **怎样走**：给一个小实例，手推变量与结构变化。
3. **怎样写**：不看答案写核心算法，必要时补给定接口。
4. **为什么对、为什么快**：说明不变量／递归关系、终止条件和复杂度。

例如学习 KMP，不仅写 Next 的最终数组，还要能说明它考察的是哪段前后缀、失配后为何不必回退文本下标，以及采用了哪种下标约定。

### 建议的一次 60 分钟训练

- 10 分钟：闭卷回忆定义、边界和性质。
- 20 分钟：完成一题手工执行，必须留下中间过程。
- 20 分钟：优先用 C 写对应核心算法或做代码填空，再用小例子核验；必要时用 Python 辅助验证。
- 10 分钟：标注错误原因，并安排后续学习时重做一个变式。

这是训练时间建议，不是估计考试分值。初期约七成精力用于本课原题／直接变式，两成用于省内高校相同知识点的题，一成用于错题整理；掌握后再调节。

### 语言安排

用户于 2026-10-22 将首选语言调整为 C：今后理解、实现、代码填空与手写算法默认使用 C，Python 按需辅助演示与验证。指针、结构体与动态内存结合具体算法训练；给定 C++ 接口的题仍按接口作答，并解释与 C 的区别。正式作答语言以老师要求为准。

参考卷并非全部采用纯 C。例如中大三份卷的题面含 `class`、`template`、引用参数等 C++ 写法（见本地 `SYSU_2008_B.txt`、`SYSU_09_B.txt`、`SYSU_10_B.txt`）。不能把“采用 C/C++ 风格的代码”当作“全部要求 C”，也不能由外校卷确定本班允许的考试语言。

Python 示例中须体现真实算法：链表用节点对象与引用；手写排序不调用 sorted；KMP 不调用 find。还要检查切片、复制、递归栈是否改变复杂度。

### 下一轮练习的最小范围

- 复杂度：增长阶比较与递推式各一组。
- 查找：同一有重复元素的序列，分别查存在、缺失、边界值，比较 A／B／C。
- 排序：一题快排分区、一题归并、一题跟踪相等元素顺序。
- 链表：一题语句顺序辨析、一题不复制节点的合并。
- 字符串：一题普通／更新版 Next、一题匹配过程与比较次数。

每一组先独立写，再对照讲义与推演核验；外校卷上的手写批注不能充当标准答案。
